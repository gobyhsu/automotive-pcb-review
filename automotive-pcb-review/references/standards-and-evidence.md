# Standards and evidence

Record the customer's required test edition, severity, supply and load mode, harness, bonding, fixture and pass criteria. Flag missing requirements before assigning numerical limits.

| Topic | Starting point |
|---|---|
| RF emissions affecting onboard receivers | [CISPR 25, IEC](https://webstore.iec.ch/en/publication/64645) |
| Component RF immunity | [ISO 11452-1, ISO](https://www.iso.org/standard/83225.html) |
| Transients and electrical loads | Select applicable parts of ISO 7637 and ISO 16750 against the project specification |
| Component qualification | Obtain the relevant AEC qualification evidence for the exact ordering code |

Separate CAD observations, model assumptions, bench results, DFM acceptance and integrated system test evidence. For example, a CAD view can locate shared sense copper, a calculation can bound the error and a calibrated test can verify the trip window. Component qualification and fabricator acceptance do not establish vehicle-level compliance.
